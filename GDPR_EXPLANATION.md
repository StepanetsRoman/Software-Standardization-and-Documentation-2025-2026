# Пояснення щодо GDPR — Trivia Quiz

Короткий опис того, як навчальний застосунок **Trivia Quiz** узгоджується з підходом **GDPR (Регламент (ЄС) 2016/679)** для **frontend-only** рішення без серверної бази даних.

> Це навчальний матеріал, а не юридична консультація адвоката.

---

## 1. Чи застосовується GDPR

GDPR може бути релевантним, якщо:

- застосунок доступний користувачам з ЄЕЗ; або
- обробляються дані, що ідентифікують особу (наприклад, повне ім’я в полі псевдоніма).

У закритій університетській лабораторії ризик нижчий, але документація все одно описує прозорість і права користувача.

## 2. Що вважається персональними даними у вікторині

| Елемент | Коментар |
| --- | --- |
| Псевдонім у URL | персональні дані, якщо це реальне ім’я |
| Історія раундів | містить псевдонім, бали, час |
| Налаштування гри | зазвичай не ідентифікують особу самі по собі |
| Згода в банері | технічний запис уподобань |

**Не обробляються:** паролі, платежі, біометрія, офіційні документи.

## 3. Підстави обробки (ст. 6 GDPR)

| Дія | Підстава |
| --- | --- |
| Збереження згоди в банері | згода 6(1)(a) |
| Локальна гра та історія | згода / надання сервісу вікторини за запитом користувача |
| Відсутність профайлінгу | автоматичні рішення щодо прав людини не приймаються |

## 4. Права суб’єкта даних

| Право | Як реалізується в Trivia Quiz |
| --- | --- |
| Прозорість | цей файл, Privacy, Cookies, банер |
| Доступ | перегляд `localStorage` у DevTools |
| Виправлення | новий псевдонім або редагування до наступного збереження |
| Видалення | очистка даних сайту / історії в UI |
| Переносимість | автоматичного експорту немає; можна скопіювати JSON з LS вручну |
| Заперечення | припинити використання застосунку |
| Відкликання згоди | скинути ключ `trivia-quiz-cookie-consent-v1` |

## 5. Міжнародна передача

У базовій збірці дані **не передаються** на сервер. Якщо ви підключите CDN або шрифти з третіх країн — опишіть це окремо при розгортанні.

## 6. DPO та реєстрація

Для студентського демо достатньо контакту виконавця та керівника. Університет може мати власного DPO для офіційних сервісів.

## 7. Технічна реалізація згоди

Банер зберігає об’єкт на кшталт:

```json
{
  "version": 1,
  "resolution": "accepted",
  "categories": {
    "necessary": true,
    "analytics": false,
    "marketing": false
  },
  "updatedAt": "2026-05-26T12:00:00.000Z"
}
```

Ключ: `trivia-quiz-cookie-consent-v1`. Перед підключенням Google Analytics перевіряйте `isAnalyticsAllowed()` у `src/utils/cookieConsent.js`.
